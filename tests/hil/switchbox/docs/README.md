## TinyG v8 switch inputs (in this repository)

`hardware/v8schematics/v8h/tinyGv8h - schematic page1.pdf` (scanned) shows, rendered at high resolution and read:
- **J7 "XY switches"**: 1 GND, 2 3.3v, 3 Xmin, 4 Xmax, 5 Ymin, 6 Ymax.
- **J8 "ZA switches"**: 1 GND, 2 3.3v, 3 Zmin, 4 Zmax, 5 Amin, 6 Amax.
- **Every switch line** has a 2.7 kΩ pull-up to +3.3 V (R10-R17) and 0.22 µF to GND (C43-C50).

The wiki page `.analysis/docs/tinyg-wiki/Homing-and-Limits-Description-and-Operation.md` confirms the 8 inputs on J7/J8. These facts are in `../boards/target/tinyg-v8.json`.

**Handling downloads:** the files were first saved to a fresh, empty directory outside the repository and inspected there; any parsing used `python3 -I`. To extract the netlist from the `.sch`:

```
python3 -I - "adafruit-pcb/Adafruit ESP8266 Feather rev G.sch" <<'EOF'
import sys, xml.etree.ElementTree as ET
root = ET.parse(sys.argv[1]).getroot()
for net in root.iter("net"):
    print(net.get("name"), sorted({f"{p.get('part')}.{p.get('gate')}:{p.get('pin')}" for p in net.iter("pinref")}))
EOF
```
